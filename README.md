# Secure Password Generator 🔐

A simple, lightweight Python command-line tool that generates cryptographically secure random passwords using Python's built-in `secrets` and `string` modules.

## Features
- Uses the `secrets` module (instead of `random`) for stronger cryptographic security.
- Combines uppercase letters, lowercase letters, numbers, and special symbols.
- Allows users to customize the desired password length.

## How to Run
1. Make sure you have Python installed on your machine.
2. Run the script in your terminal:
   ```bash
   python "python generator password.py"
   ```
3. Enter your desired password length and copy your new password!
